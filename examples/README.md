# Examples

This folder contains examples demonstrating how to use the `JsonToMany` package.

## Example: JSON to Markdown Conversion

- **`example.json`**: A sample JSON file containing document data.
- **`json_to_markdown_example.py`**: A script that converts `example.json` to Markdown format.
- **`output.md`**: The Markdown output generated by the script.

### How to Run

1. Ensure that the `JsonToMany` package is installed.

2. Navigate to the `examples` directory.

3. Run the script:

   ```bash
   python json_to_markdown_example.py
   ```
